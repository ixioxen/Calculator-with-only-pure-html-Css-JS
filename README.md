🧮 Dual Mode Calculator

A simple JavaScript calculator with two different calculation modes.

✨ Features

Normal Calculator

- Basic arithmetic operations
- Addition, subtraction, multiplication and division
- Percentage calculation
- Decimal number support
- Delete and Clear buttons

Carpet Calculator

A custom calculator designed for carpet measurement.

- Add multiple carpet pieces
- Supports yard.inch input format
- Automatically converts every 36 inches into 1 yard
- Shows total number of pieces
- Shows total yard and inch
- Calculates total price using three pricing options:
  - 3600 Kyats (Carpet + Installation)
  - 2800 Kyats (Carpet Only)
  - 800 Kyats (Installation Only)
- Automatically applies the 3500 Kyats rate for 3600 pricing when the total yard is 10 or more.
